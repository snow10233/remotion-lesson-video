# TTS 稿改寫規則（v1）

目標：把給人看的逐字稿，改成 TTS 模型照念就好的 **TTS 稿**。
核心原則：**只改寫法**。內容、用詞、語氣、句子順序都保持原樣，每個字都要能在原稿找到對應。

## 輸出格式

- 每段一行：`段號<TAB>內容`，段號三位數從 `001` 開始，依原稿順序。
- 原稿第一段（標題、說明行）不輸出。
- 一段對一段：輸出段數 = 原稿要念的段數。
- 所有段落之後空一行，接 `## 待確認`，逐條寫：段號、原文片段、你的處理、理由。沒有就寫「無」。

## 規則 1：標點只留 ，。？！（全形）

| 原本 | 改成 | 理由 |
|---|---|---|
| `：` `:` | `，` | 冒號後通常是接著說明，短停 |
| `；` `;` | `。` | 分開兩個完整子句，長停 |
| `、` | `，` | 列舉，短停 |
| `「」『』""''` | 刪掉 | 只是視覺強調 |
| `（ ）( )` | 刪括號，內容前後各加 `，` | |
| `…` `——` `—` | `，` | |
| 其他符號 | 依語意寫成文字或 `，` | 拿不準就列入待確認 |
| 半形 `,` `.` `?` `!` | 改成全形 | |

`？` `！` 保留，因為它們帶語調（問句上揚、驚嘆）。
連續兩個標點只留停頓較長的那個（。！？ 比 ， 長）。

停頓的語言：`，` = 短停、`。` = 長停。這些模型都沒有停頓標籤，停頓只能靠這兩個標點。

## 規則 2：數學與程式符號寫成中文

| 原本 | 改成 |
|---|---|
| `+` | 加 |
| `−` `-`（夾在兩個運算元之間） | 減 |
| `×` `*`（運算） | 乘 |
| `÷` `/`（運算） | 除以 |
| `=` | 等於 |
| `<` `>` `≤` `≥` | 小於、大於、小於等於、大於等於 |
| `±` | 正負 |

英文單字中間的連字號換成空格：`in-order` → `in order`、`multi-way` → `multi way`。

## 規則 3：阿拉伯數字寫成中文字

依照「講課時實際怎麼念」：
- 數值、節點的值、題目的數字：`40` → 四十、`55` → 五十五、`5` → 五、`10` → 十。
- 數量（後面接量詞）用「兩」：`2 個` → 兩個。
- 年份逐字念：`2023 年` → 二零二三年。
- 編號、負數照念：`負 1` → 負一、`第 5 條` → 第五條。
- 數字夾在英文片語裡（例如 `order 3`）：寫中文數字（order 三），列入待確認。

## 規則 4：英文照抄

- 英文術語、縮寫、句子原樣保留，大小寫不變（`AVL`、`BF`、`LL`、`Binary search tree`）。
- 念法可能有歧義的（變數名、公式寫法）：先查 `tts-glossary.md`；沒有的照原文保留，列入待確認。

## 規則 5：輸出只有文字與允許的標點

TTS 稿只包含：中文字、英文字母、半形空格、，。？！。繁簡維持原稿（轉換由腳本做），只有念法表指定的字形替換例外（例如助詞「著」寫成「着」、「於」寫成「于」）。
念法表指定的內嵌拼音（大寫拼音＋聲調數字，例如動詞「數」寫成 `SHU3`）也允許，直接黏在前後中文字上、不加空格。

## 規則 6：已知的破音字一律寫拼音

念法表列出的破音字（例如「第三行」「這一行」的行 `HANG2`、動詞的數 `SHU3`），只要用法跟念法表寫的一樣，就寫成拼音，即使模型可能本來就念得對，保險起見。`check_tts_text.py` 會擋下還沒轉的固定寫法（例如「第三行」），要看語意的（動詞的數、量）只列出提醒，逐條判斷。念法表沒有的破音字照原文保留；看起來容易念錯的列進待確認，成品有錯時使用者會回報，再補進念法表。
